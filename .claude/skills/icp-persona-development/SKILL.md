# ICP & Persona Development

Run a structured conversation to define who we sell to.

## Before you start
Read `reference/icp-and-personas.md`, `reference/company-overview.md`, and
`reference/product-catalog.md`. Note existing definitions vs placeholders.

## Conversation flow

### Part 1 — Ideal Customer Profile (the account)
Ask about and draft:
- Industry/vertical, company size, geography
- Tech/tooling and maturity signals
- Trigger events ("why now")
- Best-fit signals vs disqualifiers (who to avoid)

### Part 2 — Personas (the people)
For each persona (aim for 2–4), define:
- Title, seniority, role in the deal (economic buyer / champion / user / blocker)
- Primary goal and how success is measured
- Top pains we address
- Buying criteria and typical objections
- Where they get information (channels, communities, publications)

### Part 3 — Jobs To Be Done
Draft 3–5 statements: "When <situation>, I want to <motivation>, so I can <outcome>."

## Method
Anchor to real evidence when available (sales calls, win/loss, CRM). Where the user
is guessing, label it an assumption to validate. Don't over-segment — fewer, sharper
personas beat many vague ones.

## Output
Produce the profile using `templates/icp-persona.md`, then offer to update
`reference/icp-and-personas.md`.
