# Design Context — Athena

Shared design, brand, and marketing context for the **Athena** project (a personal AI study coach by Instructure). This folder is a self-contained briefing for the AI design team — product design, copy, brand, PMM, and GTM directors read it before giving feedback.

**This is the canonical copy.** When positioning, voice, personas, or pricing change, update these files here. Other Athena repos may carry copies of this folder; this one wins.

| File | Director(s) | Contains |
|------|-------------|----------|
| `audience.md` | All | ICP, personas, jobs-to-be-done, emotional baseline |
| `voice-and-tone.md` | Copy, Brand | Voice, tone by context, banned words, legal no-gos |
| `brand.md` | Brand, Product Design | Archetype, emotional territory, expression bar, architecture |
| `positioning.md` | PMM | Positioning, pillars, differentiation, proof points, competitors |
| `gtm-notes.md` | GTM | Motions, pricing, funnel reality, channel strategy, stage |

## The one-line spine

*Results-led, understanding-powered → precision: "the right next thing, for you" → warm expert coach → becoming more capable.* Told to students as **results**, to institutions as **the pedagogy that produces them**.

## Rules that bind every review

- **Do not invent metrics, customers, or features.** Use the documented proof points in `positioning.md` or flag the gap as a finding ("needs proof").
- **Respect public vs. internal-only info** — adoption numbers are internal-only; only the pricing in `gtm-notes.md` is public.
- **Legal/brand no-gos** (see `voice-and-tone.md`): never "FERPA compliant/certified"; never promise dashboards, admin controls, or dates; never present Athena as part of Canvas, school-endorsed, or required for coursework.
- **The gut-test for any artifact:** *Would a student feel solid — not cheap, not embarrassed — recommending this to a friend?*
