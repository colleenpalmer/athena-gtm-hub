# Launch & GTM Plan

Run a structured conversation to produce a launch/GTM plan.

## Before you start
Read `reference/positioning.md`, `reference/messaging-framework.md`,
`reference/icp-and-personas.md`, `reference/product-catalog.md`, and
`reference/competitive-landscape.md`.

## Conversation flow

1. **What & why** — What's launching, the customer problem it solves, and business goal.
2. **Launch tier** — Size the moment: Tier 1 (major, full-court press), Tier 2 (notable),
   or Tier 3 (minor/enablement-only). Set expectations accordingly.
3. **Audience** — Which personas/segments; existing customers vs new prospects.
4. **Narrative** — The launch story and 1–3 key messages (grounded in the messaging framework).
5. **Channels & assets** — Owned/earned/paid; the asset list per channel.
6. **Timeline** — Pre-launch, launch day/week, post-launch, with milestones.
7. **Owners** — RACI across product, marketing, sales, CS, support, PR.
8. **Success metrics** — Leading and lagging indicators + targets.
9. **Risks** — Dependencies, gaps, and mitigations.

## Output
Produce the plan using `templates/launch-gtm-plan.md`. Include a one-line launch
narrative, the tier, a dated timeline table, an asset checklist, and a metrics table.

## Guardrails
- Match effort to tier — don't propose a Tier 1 machine for a Tier 3 release.
- Every claim/asset must align with positioning and brand voice.
- Flag anything the reference files don't yet support.
