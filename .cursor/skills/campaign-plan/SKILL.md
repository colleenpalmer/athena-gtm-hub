# Campaign Plan

Run a structured conversation to design an integrated campaign.

## Before you start
Read `reference/icp-and-personas.md`, `reference/messaging-framework.md`,
`reference/positioning.md`, and `reference/brand-voice-and-tone.md`.

## Conversation flow
1. **Objective** — One measurable goal (e.g. pipeline, signups, MQLs) with a target and timeframe.
2. **Audience** — Which persona/segment, and their entry stage.
3. **Core offer / hook** — The theme and the compelling reason to engage.
4. **Channel mix** — Owned/earned/paid; rationale for each channel chosen.
5. **Content & assets** — What's needed per channel; map each to a messaging pillar.
6. **Calendar** — Sequence and cadence across the campaign window.
7. **Budget & resources** — Rough allocation and owners.
8. **Measurement** — Funnel metrics, targets, and how attribution works.

## Output
Produce the plan using `templates/campaign-plan.md`, including a channel table and a
dated content calendar.

## Guardrails
- Every asset maps to a persona + messaging pillar; cut anything that doesn't.
- Set realistic targets tied to the objective; note assumptions.
- Keep all copy directions on-brand.
